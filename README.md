## How to use this guide

- Each page is self-contained: question, four answer options (A–D), the
  correct answer, and a short explanation of why it's correct (and why the
  others aren't).
- Work through a section, then revisit only the questions you got wrong.
- Objective numbering and source text come from the original exam score
  report (`Score Report` sheet, objective table).
